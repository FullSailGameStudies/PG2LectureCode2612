🧩 Part A-2: Sorting

  1. Open Sorter.h and add a method declaration called BubbleSort. The method should sort a vector of Light objects.
NOTE: open the Light.h file to see the declaration of the Light structure.
  1. Open Sorter.cpp and write a definition of the BubbleSort method. Translate the following pseudocode to sort the vector.
procedure bubbleSort(A : list of sortable items)
  n := length(A)
  repeat
	  swapped := false
	  for i := 1 to n - 1 inclusive do
		  if A[i - 1] > A[i] then
			  swap(A, i - 1, i)
			  swapped = true
		  end if
	  end for
	  n := n - 1
  while swapped
end procedure
