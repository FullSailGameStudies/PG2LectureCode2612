🚀 Programming II (COP2334)

Object-Oriented Programming & Data Structures

Welcome to Programming II! This course builds directly on the foundational concepts learned in Programming I. Together, we will dive deep into object-oriented programming methodologies, inspect code performance parameters, and interact with persistent filing streams to design scalable applications.

🎯 Course Outcomes

  • Implement and utilize core OOP design patterns.
  • Utilize advanced data structures (Vectors, Maps, Lists).
  • Build large-scope programs using scheduled milestones.
  • Develop technical critical-thinking problem-solving skills.

⚙️ Required Materials

  • Development Laptop
  • Microsoft Visual Studio
  • GitHub Account
  • O'Reilly Books Online access

📅 Weekly Schedule Breakdown

Week One

Master the execution details of method scoping and alternative parameter passing rules while navigating memory constraints using vectors.

Focus: MethodsArraysVectors
Week Two

Introduce algorithmic looping techniques like recursion alongside established structures to sort, navigate, and analyze program performance indices.

Focus: RecursionPseudo-codeSorting & SearchingMaps
Week Three

Deconstruct the core architectural definitions of object-oriented design layouts (Abstraction, Encapsulation, Inheritance, and Polymorphism) inside C++.

Focus: Object-OrientedClassesInheritancePolymorphism
Week Four

Connect application data streams directly to localized filesystems to execute clean CSV serializing and deserializing patterns.

Focus: File I/OSerializing ObjectsCSV Data
